# 학습 모니터

교습소에서 선생님 컴퓨터 1대로 학생 Windows PC(4대 기준)의 화면을 확인하는 앱입니다.
같은 와이파이 안에서만 동작하며, 인터넷 서버나 외부 서비스로는 아무것도 보내지 않습니다.

| | 지원 |
|---|---|
| 선생님 컴퓨터 | Windows, Mac 모두 가능 (Node.js 필요) |
| 학생 컴퓨터 | Windows 10 / 11 |

## 구성

| 파일·폴더 | 내용 |
|---|---|
| `start.bat` | 선생님 컴퓨터가 Windows일 때 더블클릭 |
| `start.command` | 선생님 컴퓨터가 Mac일 때 더블클릭 |
| `allow-firewall.bat` | (Windows 선생님 컴퓨터, 필요할 때만) 학생 PC가 연결되지 않으면 관리자 권한으로 실행 |
| `supervisor/` | 선생님용 서버와 대시보드 |
| `student/` | 학생 PC에 복사할 폴더 |
| `tools/fake-client.js` | 학생 PC 없이 화면을 시험해 볼 때 쓰는 가짜 학생 4명 |

## 주소로 설치하기 (권장)

### 선생님 컴퓨터 (Windows)

시작 버튼을 마우스 오른쪽 클릭 > "터미널"(또는 "Windows PowerShell")을 열고 아래 한 줄을 붙여 넣은 뒤 Enter.

```powershell
[Net.ServicePointManager]::SecurityProtocol=3072; irm https://raw.githubusercontent.com/seraph0153/itc-study-monitor/main/install-teacher.ps1 | iex
```

- Node.js가 없으면 자동으로 설치를 시도합니다. (설치 동의를 묻는 질문이 나오면 `Y`)
- 바탕화면에 **ITC Study Monitor** 바로가기가 생기고, 대시보드가 열립니다. 다음부터는 바로가기만 더블클릭하면 됩니다.
- 같은 명령을 다시 실행하면 최신 버전으로 업데이트됩니다. 연결 키·설정·기록은 그대로 유지됩니다.

### 학생 PC (Windows, 한 대에 한 번)

1. 선생님 대시보드에서 **학생 PC 추가** 버튼을 누르고 명령을 **복사**합니다. (이 교실의 연결 키가 들어 있습니다)
2. 학생 PC에서 시작 버튼 오른쪽 클릭 > "터미널"을 열고 붙여 넣은 뒤 Enter.
3. `[OK] Installed.` 가 나오면 끝. 이후 로그인할 때마다 자동으로 켜지고 연결됩니다.

제거: 같은 명령에서 `-Code ...` 부분을 `-Uninstall` 로 바꿔 실행합니다.

관리자 권한은 필요 없습니다. 프로그램은 `%LOCALAPPDATA%\ITCStudyMonitorStudent` 에 설치됩니다.

## USB로 설치하기 (인터넷이 안 될 때)

### 선생님 컴퓨터

1. (처음 한 번) [nodejs.org](https://nodejs.org) 에서 Node.js LTS 버전을 설치합니다.
2. `study-monitor` 폴더 전체를 선생님 컴퓨터에 둡니다. 예: `C:\study-monitor`
3. `start.bat`(Mac은 `start.command`)을 더블클릭합니다.
   - Windows 방화벽 창이 뜨면 **개인 네트워크와 공용 네트워크 모두 체크하고 "허용"** 을 누릅니다.
4. 브라우저에 대시보드(`http://localhost:47800`)가 열립니다.
5. 끝낼 때는 검은 창을 닫습니다.

기본 상태에서는 대시보드가 서버를 켠 컴퓨터에서만 열립니다.

### 두 대에서 동시에 보기 (예: Windows 노트북 + Mac)

서버는 **한 대에서만** 켜고, 다른 컴퓨터는 브라우저로 접속합니다.

1. 서버를 켠 컴퓨터의 대시보드에서 `설정` > "다른 컴퓨터에서도 보기"에 비밀번호(8자 이상)를 정하고 `켜기`를 누릅니다.
2. 설정 창에 표시되는 주소(예: `http://192.168.0.10:47800`)를 다른 컴퓨터의 브라우저에 입력하고 비밀번호로 들어갑니다.
3. 두 화면 모두 같은 내용을 실시간으로 보고, 메시지·잠금도 양쪽에서 보낼 수 있습니다.

- 로그인은 12시간 유지됩니다. `끄기`를 누르거나 비밀번호를 바꾸면 접속 중이던 다른 컴퓨터는 바로 로그아웃됩니다.
- 켜기/끄기와 비밀번호 변경은 서버를 켠 컴퓨터에서만 할 수 있습니다.
- 비밀번호를 5번 틀리면 그 기기는 잠시 로그인이 막힙니다. 학생이 알 수 없는 비밀번호를 쓰고, 쓰지 않을 때는 꺼 두세요.
- 서버가 Windows 노트북이고 다른 컴퓨터에서 접속이 안 되면 `allow-firewall.bat` 을 관리자 권한으로 실행합니다.
- 두 대에서 서버를 각각 켜지는 마세요. 학생 PC가 둘 중 한쪽에만 붙습니다.

### 학생 PC (처음 한 번만)

1. 선생님 컴퓨터에서 `start.bat` 을 **한 번 실행한 뒤** `student` 폴더를 USB로 학생 PC에 복사합니다. 예: `C:\StudyMonitor`
   (실행하면 `student/config.txt` 에 연결 키가 자동으로 적힙니다)
2. 학생 PC에서 `install.bat` 을 더블클릭합니다.
   - Windows에 내장된 컴파일러로 `StudentAgent.exe` 를 만들고, 로그인할 때마다 자동 실행되도록 등록합니다.
3. 몇 초 안에 대시보드에 그 PC가 나타납니다.

제거: 학생 PC에서 `uninstall.bat` 실행 후 폴더 삭제.

> 먼저 시험해 보기: 선생님 노트북에서 `start.bat` 을 켠 상태로 같은 노트북의 `student\install.bat` 을 실행하면,
> 자기 화면이 대시보드에 나타나는지로 학생 프로그램이 잘 만들어지는지 확인할 수 있습니다. 확인 후 `uninstall.bat` 으로 지우면 됩니다.

### 자동으로 안 잡힐 때

- 학생 PC와 선생님 컴퓨터가 **같은 와이파이**인지 확인합니다. (게스트 와이파이는 기기끼리 통신이 막혀 있는 경우가 많습니다)
- 선생님 컴퓨터가 Windows라면 `allow-firewall.bat` 을 마우스 오른쪽 클릭 > "관리자 권한으로 실행" 합니다.
  같은 와이파이 안의 기기만 이 앱의 포트(47800, 47801)에 접속하도록 허용하는 규칙입니다.
- 그래도 안 되면 학생 PC `config.txt` 의 `server=` 뒤에 선생님 컴퓨터의 IP를 적고(대시보드 첫 화면이나 검은 창에 표시됨) `install.bat` 을 다시 실행합니다.
  IP가 바뀌지 않게 공유기에서 고정해 두면 편합니다.

## 기능

- **4분할 화면**: 3초마다 갱신. 화면을 클릭하면 크게 봅니다. 이름을 클릭하면 "1번 자리 민수"처럼 바꿀 수 있습니다.
- **딴짓 감지**: 창 제목이나 프로그램 이름에 키워드(유튜브, 게임 등)가 들어 있으면 빨간 테두리로 표시합니다. 키워드는 `설정`에서 고칩니다.
  인강을 유튜브로 본다면 `youtube`, `유튜브` 를 목록에서 빼 주세요.
- **자리비움**: 5분 이상 키보드·마우스 입력이 없으면 표시합니다.
- **메시지**: 학생 화면에 알림 창을 띄웁니다. (개별 / 전체)
- **화면 잠금**: 학생 화면을 덮고 키보드를 막습니다. 선생님 컴퓨터와 1분 이상 연결이 끊기면 자동으로 풀립니다.
- **기록**: 30초마다(딴짓이 감지된 순간은 즉시) 스크린샷을 저장하고, 창이 바뀔 때마다 활동을 기록합니다.
  `supervisor/data/날짜/PC이름/` 에 저장되며 14일이 지나면 자동 삭제됩니다. 주기와 보관 기간은 `설정`에서 바꿉니다.
- **화면 배열**: 위쪽 `배열 1·2·3·4` 로 한 줄에 보일 화면 수를 고르고, `한 화면에 맞추기` 를 켜면 스크롤 없이 모든 화면이 창 안에 들어옵니다.
  학생 화면을 마우스로 끌어 다른 화면 위에 놓으면 순서가 바뀝니다(교실 자리 배치와 맞추기). 배열과 순서는 저장되어 다음에도, 다른 컴퓨터에서 볼 때도 그대로입니다.
- **전원 끄기**: 위쪽 `전원 끄기` 로 접속 중인 학생 PC를 한꺼번에 끕니다.
  - `1분 뒤 끄기`(권장): 학생 화면에 경고가 뜨고, 1분 안에는 `끄기 취소` 로 멈출 수 있습니다. 1분 뒤에는 열린 프로그램이 강제로 닫히므로 저장하지 않은 작업은 사라질 수 있습니다.
  - `바로 끄기`: 즉시 종료를 시작합니다. 저장하지 않은 작업이 있으면 Windows가 종료를 잠시 멈출 수 있습니다.
  - 선생님 컴퓨터 자신(시험용으로 학생 프로그램을 깐 경우 포함)은 꺼지지 않습니다. 이미 꺼진 PC를 켜는 기능은 없습니다.

## 알아둘 점

- 학생 PC에서는 작업 표시줄 트레이에 아이콘이 보이고, 시작할 때 "화면이 선생님에게 공유됩니다" 알림이 뜹니다. 몰래 감시하는 방식이 아닙니다.
  학생과 학부모에게 수업 중 화면 모니터링과 기록 저장 사실을 미리 안내하고 동의를 받아 두시길 권합니다.
- 저장된 스크린샷에는 학생의 개인 정보가 찍힐 수 있습니다. `supervisor/data` 폴더를 다른 곳에 공유하지 마세요.
- 통신은 와이파이 안에서 암호화 없이(HTTP) 이루어집니다. 교습소 와이파이에 비밀번호를 걸어 두고 외부인과 공유하지 마세요.
- 학생이 작업 관리자로 프로그램을 끄면 대시보드에 "연결 끊김"으로 표시됩니다. Ctrl+Alt+Del 은 Windows 특성상 막을 수 없습니다.
